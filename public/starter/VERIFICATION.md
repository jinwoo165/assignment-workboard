# 이음 스타터 패키지 검증

검증일: 2026-11-21 / 데이터: 합성 회의록·후속 자료

## 확인한 것
- 배포 주소에서 본문 입력 → 규칙 기반 후보 3건 생성 → 편집 → 저장 실제 실행.
- 업무 완료 처리, 본인 메모 저장 후 페이지 새로고침: 기록 유지.
- 후속 자료를 기존 완료 업무에 반영: 전체 3건 유지, 완료 상태·메모 보존, 근거 1건 → 2건.
- 핵심 자동 검사 6개 통과: 완료·메모·보관 보존, 출처 중복 방지, 잘못된 행의 일괄 반영 차단, 위험 URL·잘못된 날짜 차단, 상대 날짜 비확정, 중복 AI ID 차단, 백업 직렬화 왕복.
- 기존 로그인형 프로젝트의 자동 검사 165개 통과.

## 검증 범위의 한계
- 자동 검사와 실제 브라우저 조작을 구분한다. AI 결과 JSON 검증·병합, 백업 읽기는 코드 검사로 확인했다.
- 이번 검증에서 실제 개인 AI API, 직원별 계정·자료 수집·예약 실행은 호출하지 않았다.
- 모든 브라우저의 file:// 저장 동작, 다수 직원 환경, 동시 저장 부하, 브라우저 저장 용량 초과는 검증하지 않았다.
- 실제 운영 업무보드와 데이터베이스는 변경하지 않았다. 독립형 실행본은 기존 로그인형 사이트와 별도 브라우저 저장 키를 사용한다.

`node --test tests/core.test.cjs`로 기본 데이터 규칙 검사를 재현할 수 있다. 예제 회의록으로 등록·상태 변경·새로고침을 직접 확인할 수 있다.
