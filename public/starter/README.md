# 이음 스타터 패키지
## 흘러가는 자료를, 계속되는 내 업무로

이음은 자료를 요약해서 쌓아두는 대신, 내가 해야 할 일·다음 행동·기한·근거를 함께 관리하는 개인 업무 실행 공간입니다.

### 3분 시작
1. 압축을 풀고 `index.html`을 Chrome 또는 Edge로 엽니다. 파일을 이동하면 브라우저 저장 위치가 달라질 수 있으므로 같은 위치에서 사용하세요.
2. **자료 넣기 → 예제 회의록 넣기 → 할 일 후보 찾기**를 누릅니다. 예제는 합성 자료입니다.
3. 내 업무만 선택하고 제목·기한·다음 행동을 수정한 뒤 **선택한 업무 저장**을 누릅니다.
4. 상태를 진행 중·완료로 바꾸고 업무를 눌러 메모를 남깁니다. 새로고침해서 유지되는지 확인합니다.
5. **백업 받기**로 JSON 파일을 저장합니다. 다른 브라우저에서는 **백업 복원**으로 가져옵니다.

### 무엇이 실제로 작동하나요?
- TXT/MD/CSV 원문 읽기, 본문 붙여넣기, 문장 규칙에 따른 할 일 후보 추출
- 사람이 확인한 업무 저장, 기존 업무 선택 병합, 완료·메모 보존
- 업무 검색·기한·상태·보관, 달력, 변경 이력, 원문 링크, 근거 확인
- 저장된 기록으로 보고 초안 다운로드, JSON 백업과 복원
- 개인 AI 요청 파일 생성 및 `ieum.import` JSON 결과 가져오기

후보 찾기는 AI가 아닙니다. 사람의 담당 구분, 복잡한 의도 파악과 상대 날짜 해석을 보장하지 않습니다. 날짜는 명시된 YYYY-MM-DD/YYYY.MM.DD/YYYY/MM/DD만 후보로 읽습니다. 기한이 없거나 불확실하면 비워두세요. 자연어 분석이 필요하면 AI 정리 요청 파일을 활용합니다.

### 내 AI에게 설치를 맡기려면
`AI_START.md`와 전체 패키지를 파일 편집·실행이 가능한 AI에게 전달하세요. 일반 채팅에서는 지침과 자료를 읽고 분석 결과를 생성할 수 있지만, 사용자의 PC 설치나 예약 실행 권한까지 자동으로 생기지는 않습니다.

자료를 주고 AI에게 `examples/ai-result.json`과 같은 형식의 파일을 요청합니다. 이음의 자료 넣기에서 JSON을 선택하고 저장합니다. 기존 업무를 수정할 때는 이음에서 받은 AI 정리 요청에 포함된 기존 ID를 유지합니다.

### 저장과 운영
- 기본판은 서버, 로그인, API 키 없이 동작합니다. 원본 파일 자체는 저장하지 않고 선택된 업무·근거를 이 브라우저 localStorage에 저장합니다.
- 공유 PC에서는 같은 브라우저 사용자에게 내용이 보입니다. 브라우저 데이터 삭제·시크릿 창 종료로 기록을 잃을 수 있습니다. 민감한 자료는 회사 기준에 맞는 환경에서 사용하고 백업하세요.
- 동시에 여러 창에서 수정하면 충돌 안내를 띄우고 오래된 창의 저장을 차단합니다. 동시 편집 서버는 아닙니다.
- 이 실행본과 기존 로그인형 이음의 데이터는 자동으로 동기화되지 않습니다. 기존 로그인형 서비스는 별도 기능으로 유지됩니다.
- OneDrive에 HTML과 백업을 보관하는 것만으로 자동 분석·동기화되지는 않습니다.
- AI 자동 호출, 수집·폴더 감시·예약 실행·사용자 인증은 추가 구현 범위입니다. 관련 계정 등록·사용 권한·비용은 환경에 따라 확인해야 합니다.

### 개발자 실행
설치 없이 HTML을 열어 실행할 수 있습니다. 로컬 웹서버를 선호하면 Python 3가 설치된 PC에서 `python -m http.server 8765 --bind 127.0.0.1` 실행 후 `http://127.0.0.1:8765`로 접속합니다. 외부 공개 서버가 아닙니다.

코드: `index.html` 화면 구조 / `style.css` 디자인 / `core.js` 자료 규격·검증·병합 / `app.js` 사용자 동작·저장. Node.js가 있으면 `node --test tests/core.test.cjs`로 핵심 로직을 검사할 수 있습니다.

배포할 때 이 폴더의 정적 파일을 독립 경로에 올리면 됩니다. 브라우저 원본(origin)이 달라지면 기존 기록은 자동 이동하지 않습니다. 백업·복원을 사용하세요.

기본판에 실제 계정, API 키, 사용자 업무 자료는 포함되어 있지 않습니다.
