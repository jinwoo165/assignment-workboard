## 시각 효과

- 데스크톱 첫 진입과 명시적 새로고침: 원형으로 펼쳐지는 화면, 패널 순차 등장.
- 메뉴 전환: 선택 표시가 이동하고 본문이 짧게 전환된다. 키보드 포커스를 유지한다.
- 업무 필터: 목록이 짧은 간격으로 나타난다.
- 진행률: 기존 계산값·원형 그래프·100% 기준 5초의 비례 시간을 유지하며 숫자 자릿수를 회전시킨다.
- 메뉴 설명, 카드·버튼 반응, 상세창·설정창·알림의 짧은 등장 효과.
- 색상과 레이아웃은 기존 설정을 따르며, 주요내용 타이핑 효과는 추가하지 않았다.
- 배경 데이터 갱신은 첫 진입 효과를 재시작하지 않는다. 운영체제의 동작 줄이기 설정을 따른다.
- 모바일의 기존 숫자 즉시 표시와 목록 스크롤 구조를 유지한다.

## 복원 방법

이번 변경은 독립된 커밋으로 기록한다. 이 문서 최초 추가 커밋을 `git log --diff-filter=A -- handoff/VISUAL-MOTION-20261124.md`로 찾을 수 있다.

1. 현재 `main`과 이후 변경을 먼저 확인한다.
2. 이번 효과만 취소하려면 해당 커밋을 `git revert`하여 새 커밋으로 남긴다. 이후 변경과 충돌하면 이번 효과와 관련된 부분만 제거한다.
3. 사용자가 당시 화면 전체 복원을 요청하고 이후 변경도 취소하는 데 동의했다면 북마크의 파일 트리를 새 복원 커밋으로 반영한다. `main`의 이력을 강제로 덮어쓰지 않는다.
4. 저장소 필수 검사와 빌드를 수행하고, GitHub Pages 배포 성공 및 실제 주소의 버전·메뉴·진행률을 확인한다.
5. DB·사용자 데이터·브라우저 저장값은 이번 효과 변경에서 수정하지 않았으므로 복원 작업에서도 초기화하지 않는다.
