# 과제용 개인 업무보드 구축 기록

기준일: 2026-11-20 (Asia/Seoul)

## 확정한 범위
- 운영 중인 개인 업무보드와 코드·DB·배포·인증·AI 연결을 분리한다.
- 운영 업무보드 전체 화면과 기능을 유지하고, 개인 AI 연결만 ChatGPT/Claude 선택 구조로 변경한다.
- 실제 업무보드로 발표하되 과제용에서도 핵심 기능이 직접 실행돼야 한다.
- 자료 수집은 개인 AI가 접근 권한을 가진 원본에서 수행한다. 업무보드에 AI 선택값만 저장하는 것은 연결 성공이 아니다.

## 최신 확정 원칙 및 구현
다한닷·특정 AI·OneDrive 연결은 필수가 아니다. 흐르는 대화·메일·회의록·보고서를 내 업무와 다음 행동으로 연결해 지속 관리한다.
- 내 자료 가져오기: TXT/MD/CSV/EML/JSON 파일 및 폴더 선택(100개/700KB), 본문 붙여넣기.
- 원문은 브라우저에서 읽는다. 파일 원본 저장 또는 내장 AI 분석을 수행하지 않는다.
- 기존 업무 ID·상태·메모와 원문을 포함한 공통 AI 분석 지침 복사.
- 개인 AI 결과 JSON 가져오기→업무명/기한/다음 행동 수정→새 업무 또는 기존 업무 연결→본인 공간 저장.
- 이전 출처 병합, 기존 완료/메모 보존, 원문 변경 검토, 변경 이력은 기존 DB 로직 활용.
- 직접 업무 작성도 동일 확인 흐름으로 지원한다.
- PDF/Office/이미지 원문 분석, 폴더 자동 감시, 무인 수집, 일정/독립 바로가기 JSON 가져오기는 후속 범위다. 출처 링크는 업무 안에 저장한다.
- 자동 수집 성공 상태를 만들어내지 않는다.

## 완료 수준 표기
코드 구현·로컬 검사·배포·실제 계정 테스트·자동 수집은 별도로 기록한다. 기존 로그인/대화 검증이 새 가져오기 기능의 실사용 검증을 대신하지 않는다.
