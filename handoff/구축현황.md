# 과제용 개인 업무보드 구축 기록

기준일: 2026-11-20 (Asia/Seoul)

## 확정한 범위
- 운영 중인 개인 업무보드와 코드·DB·배포·인증·AI 연결을 분리한다.
- 운영 업무보드 전체 화면과 기능을 유지하고, 개인 AI 연결만 ChatGPT/Claude 선택 구조로 변경한다.
- 실제 업무보드로 발표하되 과제용에서도 핵심 기능이 직접 실행돼야 한다.
- 자료 수집은 개인 AI가 접근 권한을 가진 원본에서 수행한다. 업무보드에 AI 선택값만 저장하는 것은 연결 성공이 아니다.

## 원본과 복제
- 소스: jinwoo165/dahandot-workdesk, v2.14.1.
- 읽기 기준 commit: 9b7a34ae59ea87dc2704d772c6d9b62b32f96f33.
- 소스 파일을 새 디렉터리로 복사했다. 운영 Git 메타데이터·기존 빌드·환경값은 포함하지 않는다.
- 운영 GitHub 저장소·Supabase에 쓰기 요청을 보내지 않았다.
- 운영 DB는 테이블 구조와 별도 후속 이행 테이블의 스키마만 조회했다. 업무·메일·대화·파일 원문 행은 복사하지 않았다.
- 이 패키지는 데이터 백업이 아니다. 원본 자료의 전체 백업·복구 성공을 주장하지 않는다.

1. 새 Supabase 프로젝트를 만들 조직 지정. 현재 연결 계정에서 보이는 조직은 6044@hdc-dvp.com's Org.
2. 신규 프로젝트의 비용 확인 및 생성, DB 초기 설치.
3. 신규 Auth의 Site URL/Redirect URL, 메일 발송 설정. Microsoft/Google 사용 시 각 provider 앱 설정.
4. 별도 비공개 GitHub 저장소, 배포 환경 및 변수 지정.
5. 개인 AI MCP를 위한 OAuth 서버 설정, client 허용 및 직원별 연결.
6. 실제 신규 계정 로그인→저장→다른 계정 차단→로그아웃/재접속 시험.
